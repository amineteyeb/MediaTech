# 📚 Médiatech — Smart Digital Library & Media Reservation Platform

A modern cross-platform digital library management system built with Flutter, Riverpod, and Firebase.

Médiatech reimagines the traditional library experience through an intelligent reservation and loan management system combined with a professional modern UI/UX.

The platform allows users to browse multimedia resources, reserve media with custom loan periods, manage queues, and track borrowing history, while administrators can efficiently manage reservations, loans, and the entire media catalogue.

# 🧠 Intelligent Reservation System

Instead of directly borrowing media, users submit reservation requests.

## Reservation Workflow
1. User selects:
   - Start date
   - End date

2. Reservation request is sent to administrators

3. Admin can:
   - ✅ Approve
   - ❌ Reject

4. Approved reservations become active loans

### Additional Features
- Queue management for unavailable media
- Queue position tracking
- Reservation status updates
- Loan duration management
- Extension requests
- Return system
- Overdue detection
